# Голос на хакатоне: распознавание и синтез речи

С 18.11 ваш ключ нейросети умеет не только чат, но и голос. Ничего нового получать не нужно.

## Адрес, ключ, модели

- Адрес и ключ — **те же, что для чата**: `LLM_BASE_URL` и `LLM_API_KEY` (в env бэкенда на стенде; на ноутбуке —
  адрес из README набора и `llm.key`).
- Модели, писать ровно так:

| Что | Модель |
|---|---|
| Распознавание речи (STT) | `gpt-transcribe` |
| Синтез речи (TTS) | `tts-1` |
| Чат (как было) | `gpt-6-luna` |

Раньше `/v1/audio/transcriptions` отвечал ошибкой, потому что ключ пускал только в `gpt-6-luna`. Теперь — с моделями из таблицы.

## Лимиты на команду — в сутки, сброс в 00:00 МСК (ключ действует до 23.11, 12:00 МСК)

- **Распознавание (STT) — $3 в сутки** на `gpt-transcribe` (около 11 часов аудио). До 10 запросов в минуту.
- **Синтез (TTS) — $3 в сутки** на `tts-1` (около 200 тыс. символов). До 10 запросов в минуту.
- Каждый день в 00:00 МСК расход обнуляется, вместе с суточным лимитом чата.
- Запросы голоса считаются и в общие 30 запросов в минуту вашего ключа. Чат и его лимит прежние.
- Бюджет на сегодня кончился — ответ **402** (до 00:00 МСК), слишком часто — **429** (подождите минуту),
  файл больше 5 МБ — **413**. Не хватает — пишите организаторам.

## Пример (Python, `pip install openai`)

```python
import os
from openai import OpenAI

client = OpenAI(base_url=os.environ["LLM_BASE_URL"], api_key=os.environ["LLM_API_KEY"])

# Распознавание: байты записи, имя файла с правильным расширением (по нему определяется формат)
with open("question.webm", "rb") as f:
    audio_bytes = f.read()
text = client.audio.transcriptions.create(
    model="gpt-transcribe",
    file=("question.webm", audio_bytes, "audio/webm"),   # файл до 5 МБ
    language="ru",
    response_format="json",            # только json
).text

# Синтез: mp3-байты, их можно сразу отдать браузеру (Content-Type: audio/mpeg)
speech = client.audio.speech.create(
    model="tts-1",
    voice="alloy",                     # ещё echo, fable, onyx, nova, shimmer
    input="Здравствуйте! Чем могу помочь?",
    response_format="mp3",
)
mp3_bytes = speech.content
```

## Форматы и размер

- STT принимает **mp3, wav, webm** (запись из браузера через `MediaRecorder`), а также m4a, ogg, flac.
  Передавайте имя файла с расширением, как в примере.
- `response_format` у STT — **только `json`** (он и по умолчанию), текст в поле `text`. `text`, `srt`, `vtt`
  не используйте.
- **Файл — до 5 МБ**, больше прокси не пропустит (413). Это около 5 минут mp3 128 кбит/с, 10 минут и больше
  webm/opus из браузера, но всего около 2,5 минуты wav 16 кГц моно. Длинную запись сжимайте (webm, mp3)
  или режьте на части.
- TTS: до 4096 символов за запрос, формат mp3.

## Ключ — только на бэкенде

Ключ **не кладите во фронтенд** и в репозиторий. Схема: браузер записывает звук и отправляет его **в ваш
бэкенд**, бэкенд вызывает прокси с ключом из env и возвращает браузеру текст или mp3. С бэкенда на стенде
адрес прокси уже открыт, настраивать ничего не нужно.

## Проверка через `/run`

В ответах `/run` реплики **по-прежнему текстовые**, как в README набора. Голос — для вашего интерфейса и демо.
